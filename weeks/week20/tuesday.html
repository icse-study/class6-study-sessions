Functions Deeper — Parameters & Return Values
Functions are named mini-programs. This week: giving them inputs (parameters), getting results back (return), and where variables live (scope).
📥 Parameters and arguments
def greet(name):        # name is a PARAMETER
    print("Hi", name)

greet("Asha")           # "Asha" is an ARGUMENT

A parameter is the name in the definition; an argument is the real value you pass in.

📤 return gives a value back
def add(a, b):
    return a + b

result = add(2, 3)     # 5
print(add(2, 3) * 10)  # 50

print only shows a value. return hands it back so you can use it. Code after return never runs. A function with no return gives back None.

🧰 Practice functions
def is_even(n):
    return n % 2 == 0

def find_max(a, b, c):
    biggest = a
    if b > biggest:
        biggest = b
    if c > biggest:
        biggest = c
    return biggest

def power(base, exp=2):    # default value
    return base ** exp
🏠 Local vs global

“Variables made inside a function stay inside.” A local variable disappears when the function ends. A global variable, made outside, can be read inside a function.

x = 1
def change():
    x = 99      # a NEW local x
change()
print(x)        # still 1
✨ Fun facts
• The idea “Don’t Repeat Yourself” (DRY) is a famous rule in programming — functions are the main way to follow it.
• Python has more than 60 built-in functions, such as print(), len(), max() and input().
• A function can return several values at once — Python packs them into a tuple.
