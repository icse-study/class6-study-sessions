Debugging Practice & Common Errors
Every programmer makes mistakes. Good programmers know how to find and fix them. Don’t panic — read the error message!
🐞 Three kinds of error

Syntax error — breaks Python’s grammar, so the program will not start (missing colon, bracket or quote). Runtime error — the program starts but crashes while running (dividing by zero, a missing key). Logic error — the program runs but gives the wrong answer.

📖 Reading an error message
Traceback (most recent call last):
  File "game.py", line 3, in <module>
    print(scor)
NameError: name 'scor' is not defined

Look at the last line (the error type and message) and the line number. The real mistake is on that line or just before it.

🔍 Common mistakes
if x > 5            # SyntaxError: missing colon
print("hi"          # SyntaxError: missing bracket
Prnt("hi")          # NameError: misspelled
if x = 5:           # SyntaxError: use ==
"5" + 5             # TypeError: text + number
int("ten")          # ValueError
nums[3]             # IndexError if nums has 3 items
10 / 0              # ZeroDivisionError
d["missing"]        # KeyError
🧠 Logic bugs
average = a + b / 2        # wrong: should be (a + b) / 2
for i in range(1, 10):     # prints 1–9, not 1–10 (off by one)
if score > 50:             # 50 itself is missed — use >=
while x < 5:               # forgot x = x + 1 → infinite loop
    print(x)
🛠️ Fixing strategy

1. Read the error message. 2. Go to the line number. 3. Check spelling, colons, brackets, quotes and indentation. 4. Add print() lines to see what values really are. 5. Fix one thing, then run again. 6. Still stuck? Explain the code out loud (rubber duck debugging).

✨ Fun facts
• The word “bug” for a fault in a machine was used by Thomas Edison back in the 1870s.
• NASA lost its Mars Climate Orbiter in 1999 because one team used imperial units and another used metric — a costly logic bug.
• “Off-by-one” errors are so common that programmers joke there are only two hard things in computing: naming things and off-by-one errors.
