💻 CS / Python · Week 19 · Revision + Mini Project 1
Revision & Mini Project — Pattern Printer
Revise for loops, while loops, range() and nesting — then build a Pattern Printer: the user picks a shape and a size, and the program draws it.
🔁 Quick recap

for — known number of repeats · while — repeat until a condition changes · range(start, stop, step) — stop is excluded · nested — inner loop finishes for every outer pass · break leaves a loop early · continue skips to the next pass.

🛠️ Mini Project — Pattern Printer
def square(n):
    for i in range(n):
        print("*" * n)

def triangle(n):
    for i in range(1, n + 1):
        print("*" * i)

choice = ""
while choice != "q":
    choice = input("square, triangle or q to quit: ")
    if choice == "square" or choice == "triangle":
        size = int(input("Size: "))
        if choice == "square":
            square(size)
        else:
            triangle(size)

input() always gives text; int() turns it into a number.

🧪 Plan → Code → Test → Improve

Test edge cases: size 0, size 1, a very big size, and a word instead of a number. Then improve: add a pyramid, a hollow square, or let the user choose the symbol.
