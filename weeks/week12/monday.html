➗ Quick recall sheet

Vocabulary

Variable — a letter whose value can change (x in 3x + 5).
Constant — a fixed value (the 5).
Coefficient of x in −5xy → cover the x: −5y.
Monomial / binomial / trinomial — 1 / 2 / 3 unlike terms.
Degree — the highest power of the variable: 4x³ − 2x + 8 has degree 3.
An expression with a variable in a denominator (5x + 1/x) is not a polynomial.

The four operations

Add / subtract: only like terms combine · 7x + 3y − 2x + 5y = 5x + 8y
Brackets: a minus outside changes every sign inside · (8a − 2b) − (5a + 3b) = 3a − 5b
Multiply: multiply coefficients, add exponents · (a²b)(−3ab²) = −3a³b³
Divide: divide coefficients, subtract exponents · 8x⁴ ÷ 2x² = 4x²

Identities and patterns

(a + b)(a − b) = a² − b² · (a + b)² = a² + 2ab + b²
Sum of first n even numbers = n(n + 1) · Sum of first n odd numbers = n²

Integers (Chapter 4 recall)

Same signs → add and keep the sign. Different signs → subtract and take the sign of the larger. Subtracting a negative is adding.

(−5) + (−9) = −14  ·  (−8) − (−5) = −3
