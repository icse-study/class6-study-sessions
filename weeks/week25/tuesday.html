🐛 Debug-the-code
def add(a, b)          # missing colon
    return a + b

for i in range(5):
print(i)               # missing indentation

if x = 5:              # should be ==
    print("five")

print("Hello)          # missing closing quote

total = 0
for n in [1, 2, 3]:
    total = n          # logic bug: should be total = total + n

Syntax errors stop the program from running. Logic errors run but give the wrong answer.

✨ Fun facts
• Grace Hopper, a pioneer of programming, made “debugging” famous after a moth was found in a computer.
• Many professional programmers explain their code out loud to a rubber duck to find bugs — called “rubber duck debugging”.
• Python’s error messages tell you the line number — always read them!
