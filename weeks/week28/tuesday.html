💻 CS / Python · Week 28 · Mini Project 2
Turtle Mini Project — Draw a Scene
Combine functions + loops + turtle to draw a house, a garden or a landscape. Each part of the scene gets its own function.
🗺️ Plan first

Sketch your scene on squared paper. Mark coordinates: x goes right (positive) and left (negative); y goes up (positive) and down (negative). Draw the background first (sky, grass), then things in front.

🧱 Building blocks
def rect(x, y, w, h, colour):
    t.penup()
    t.goto(x, y)
    t.pendown()
    t.color(colour)
    t.begin_fill()
    for i in range(2):
        t.forward(w)
        t.left(90)
        t.forward(h)
        t.left(90)
    t.end_fill()

def sun(x, y):
    t.penup(); t.goto(x, y); t.pendown()
    t.color("yellow")
    t.begin_fill(); t.circle(40); t.end_fill()
🏠 Putting it together
turtle.bgcolor("skyblue")
rect(-300, -200, 600, 100, "green")   # grass

def house(x, y):
    rect(x, y, 100, 100, "brown")      # walls
    # roof: a triangle on top, turning 120 each corner
    rect(x + 40, y, 20, 40, "black")   # door

house(-150, -100)
house(50, -100)          # reuse!
sun(200, 150)
for i in range(5):
    rect(-200 + i * 100, -150, 10, 30, "saddlebrown")   # tree trunks
🎤 Present it

Show your scene and say: what it does, one thing you learned, and one bug you fixed.

✨ Fun facts
• Animated films are planned the same way — artists draw the background first, then the characters on top.
• Programmers call hiding the details inside a named function “abstraction”.
• Some digital artists create whole galleries of art using only code.
🧠 Trivia — try first, then tap to check
1. Why lift the pen before goto()?
👀 Show answer
To avoid drawing a stray line.
2. What is drawn first: background or foreground?
👀 Show answer
Background — later drawings go on top.
3. What does house(50, -100) show about functions?
👀 Show answer
They can be reused with different values.
🎯 Must-remember
• penup → goto → pendown
• background first, foreground last
• one function per part, with x, y parameters
