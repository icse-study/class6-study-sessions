Turtle Graphics — Drawing with Code
turtle lets you steer a little pen around the screen with code. You see your program draw instantly!
🐢 First steps
import turtle
t = turtle.Turtle()

t.forward(100)    # move 100 steps
t.right(90)       # turn right 90 degrees
t.forward(100)

turtle.done()     # keep the window open

The turtle starts at the centre (0, 0), facing right (east).

🕹️ Basic commands

forward(n) · backward(n) · right(angle) · left(angle) · penup() — move without drawing · pendown() — draw again · goto(x, y) — jump to a point · speed(0) — fastest.

⬛ Square and triangle
# square: 4 sides, turn 90 each time
for i in range(4):
    t.forward(100)
    t.right(90)

# triangle: 3 sides, turn 120 each time
for i in range(3):
    t.forward(100)
    t.right(120)

Turn angle = 360 ÷ number of sides. For any closed shape, the turtle turns a total of 360°.

✨ Fun facts
• Turtle graphics come from the Logo language, created in the 1960s by Seymour Papert and colleagues to teach children programming.
• The first Logo “turtles” were real robots that crawled on the floor with a pen.
• Python’s turtle module is built in — no installing needed.
