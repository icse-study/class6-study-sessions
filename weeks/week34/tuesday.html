Python Modules — random, math & time
A module is a file of ready-made code you can import. Python comes with hundreds — “batteries included”.
🎲 random
import random
random.randint(1, 6)        # dice: 1 to 6
random.choice(["yes", "no"]) # pick one
cards = [1, 2, 3, 4]
random.shuffle(cards)       # mixes the list itself, returns None
random.random()             # a decimal from 0 up to (not including) 1
📐 math
import math
math.sqrt(16)     # 4.0
math.pi           # 3.141592653589793
math.floor(3.7)   # 3   (round down)
math.ceil(3.2)    # 4   (round up)
math.floor(-2.5)  # -3
math.pow(2, 3)    # 8.0   (2 ** 3 is 8)

from math import sqrt   # then just sqrt(25)
⏱️ time
import time
for i in range(3, 0, -1):
    print(i)
    time.sleep(1)    # wait 1 second
print("Lift off!")
🛠️ Mini activities
# magic 8-ball
answers = ["Yes!", "No.", "Ask again later"]
print(random.choice(answers))

# two dice
total = random.randint(1, 6) + random.randint(1, 6)   # 2 to 12

You can rename a module: import random as rd then rd.randint(1, 6).

✨ Fun facts
• Python’s standard library has over 200 modules — for dates, files, the internet, maths and much more.
• math.pi is accurate to about 15 decimal places — more than NASA needs for most space missions.
• Python has an Easter egg: import this prints “The Zen of Python”, a poem of programming advice.
