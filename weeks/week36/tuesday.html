List Methods + String Methods Recap
Lists and strings come with built-in methods — tools you call with a dot. Use them to build a word counter and a to-do list manager.
📋 List methods
a = [3, 1, 2]
a.append(4)       # [3, 1, 2, 4]  add to end
a.insert(0, 9)    # [9, 3, 1, 2, 4]  add at a position
a.remove(9)       # removes the first 9
x = a.pop()       # removes and returns the last item
a.pop(0)          # removes and returns the first item
a.sort()          # sorts the list itself (returns None)
a.sort(reverse=True)
a.reverse()       # reverses the list itself
len(a)            # number of items
sorted(a)         # a NEW sorted list; a is unchanged

remove on a value that is not there gives a ValueError.

🔤 String methods
s = "  Hello World  "
s.upper()                      # "  HELLO WORLD  "
s.lower()
s.strip()                      # "Hello World"
"a,b,c".split(",")             # ['a', 'b', 'c']
"hello world".replace("world", "there")
"banana".count("a")            # 3

Strings are immutable: s.upper() makes a new string — s itself does not change unless you write s = s.upper().

🛠️ Practice
# word frequency counter
words = "the cat and the hat".split()
freq = {}
for w in words:
    freq[w] = freq.get(w, 0) + 1

# to-do list manager
tasks = []
tasks.append("homework")
tasks.append("practise piano")
tasks.remove("homework")
print(len(tasks), "task(s) left")
✨ Fun facts
• Python’s sort uses an algorithm called Timsort, invented in 2002 by Tim Peters especially for Python.
• A method is just a function that belongs to an object — that is why it needs a dot.
• You can chain methods: " HI ".strip().lower() gives "hi".
🧠 Trivia — try first, then tap to check
1. What does a.pop() return?
👀 Show answer

2. Does s.upper() change s?
👀 Show answer

3. What is the difference between a.sort() and sorted(a)?
👀 Show answer
sort changes a; sorted returns a new list.
🎯 Must-remember
• append · insert · remove · pop · sort · reverse · len
• sort() returns None; sorted() returns a new list
• upper · lower · strip · split · replace · count
• strings are immutable
