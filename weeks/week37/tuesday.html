Project Week — Quiz Game or Text Adventure
Build a bigger program by breaking a big problem into small steps (called decomposition). Choose a quiz game or a mini text adventure.
❓ Project A — Quiz game
quiz = {
    "Capital of India?": "New Delhi",
    "2 + 2 = ?": "4",
    "Largest planet?": "Jupiter",
}
score = 0
for q in quiz:
    ans = input(q + " ").strip()
    if ans.lower() == quiz[q].lower():
        print("Correct!")
        score = score + 1
    else:
        print("Sorry, it was", quiz[q])
print("Score:", score, "/", len(quiz))
print("Percent:", score / len(quiz) * 100)
🗺️ Project B — Text adventure
rooms = {
    "hall":    {"north": "kitchen", "east": "library"},
    "kitchen": {"south": "hall"},
    "library": {"west": "hall"},
}
current = "hall"
inventory = []
while True:
    print("You are in the", current)
    move = input("Go where? (or quit) ")
    if move == "quit":
        break
    if move in rooms[current]:
        current = rooms[current][move]
    else:
        print("You can’t go that way!")

Checking if move in rooms[current] stops a KeyError when the player types a wrong direction.

🧩 Decomposition

Split the project: (1) store the data, (2) ask a question or show a room, (3) read the player’s answer, (4) check it, (5) update score or position, (6) repeat, (7) finish. Build and test one step at a time. A flowchart helps plan the paths.

✨ Fun facts
• The first text adventure game, Colossal Cave Adventure, was written in the 1970s.
• Decomposition is one of the four pillars of “computational thinking”, along with patterns, abstraction and algorithms.
• Quiz apps you use online work exactly like this — questions and answers stored as data.
