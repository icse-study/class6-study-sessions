Dictionaries — Keys and Values
“Like a real dictionary — look up a word (the key) to get its meaning (the value).”
📖 Making a dictionary
student = {"name": "Aarav", "age": 11}
print(student["name"])   # Aarav

Curly braces {}, pairs written key: value, separated by commas.

✏️ Add, change, delete
student["class"] = 6      # add
student["age"] = 12       # change
del student["age"]        # delete
x = student.pop("class")  # remove and return 6
print(len(student))       # number of pairs
🔍 Safe looking-up
student["marks"]          # KeyError if missing!
student.get("marks", 0)   # 0 if missing
"name" in student         # True — checks KEYS
🔁 Looping
marks = {"Ria": 90, "Om": 80}
for name in marks:              # keys
    print(name)
for name, m in marks.items():   # keys and values
    print(name, m)
print(sum(marks.values()))      # 170
📏 Rules

Keys are unique — writing the same key again replaces the value. Keys must be unchangeable types (strings, numbers, tuples), so a list cannot be a key. Values can be anything.

✨ Fun facts
• Python dictionaries remember the order you add items (since Python 3.7).
• Dictionaries are extremely fast: looking up one key is just as quick in a dictionary of a million items.
• Websites send data in a format called JSON, which looks almost exactly like a Python dictionary.
