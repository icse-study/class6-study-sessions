Algorithms — Flowcharts & Pseudocode
An algorithm is a clear, step-by-step set of instructions that ends. Plan one with a flowchart or pseudocode before you write real code.
🔷 Flowchart symbols

Oval — Start / End · Rectangle — Process (do something, e.g. total = total + 1) · Diamond — Decision (a yes/no question, two exits) · Parallelogram — Input / Output (read age, show answer) · Arrows — the flow. An arrow going back up makes a loop.

🧱 Three building blocks

Sequence — steps in order · Selection — choosing (IF … ELSE) · Repetition — looping (WHILE, FOR).

📝 Pseudocode
INPUT number
IF number MOD 2 = 0 THEN
    OUTPUT "even"
ELSE
    OUTPUT "odd"
ENDIF

INPUT a, b, c
biggest = a
IF b > biggest THEN biggest = b
IF c > biggest THEN biggest = c
OUTPUT biggest

Pseudocode is plain-English, code-like steps — not a real language. INPUT → input(), OUTPUT → print(), IF → if.

🪥 Activity

Draw a flowchart for brushing your teeth: Start → pick up brush → put on paste → Is it 2 minutes yet? (No → keep brushing, loop back) → rinse → End.

✨ Fun facts
• The word “algorithm” comes from the name of al-Khwarizmi, a 9th-century Persian mathematician.
• A recipe is an algorithm for cooking — inputs (ingredients), steps, and an output (the dish).
• Searching a list by checking items one by one is called linear search.
