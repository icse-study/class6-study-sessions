Project Week — Guess the Number & Rock Paper Scissors
Build two classic games using random, while, if/elif/else and functions. Focus: planning → coding → testing → showing.
🔢 Project A — Guess the Number
import random
secret = random.randint(1, 100)   # 1 to 100, both included
guesses = 0
guess = 0
while guess != secret:
    guess = int(input("Guess: "))
    guesses = guesses + 1
    if guess < secret:
        print("Too low")
    elif guess > secret:
        print("Too high")
print("Got it in", guesses, "guesses!")

Best strategy: always guess the middle of what is left (50, then 25 or 75…). You never need more than 7 guesses for 1–100.

✊ Project B — Rock Paper Scissors
import random
choices = ["rock", "paper", "scissors"]

def winner(p, c):
    if p == c:
        return "draw"
    if (p == "rock" and c == "scissors") or \
       (p == "paper" and c == "rock") or \
       (p == "scissors" and c == "paper"):
        return "player"
    return "computer"

score = {"player": 0, "computer": 0}
p = input("rock, paper or scissors? ")
c = random.choice(choices)
w = winner(p, c)
if w != "draw":
    score[w] = score[w] + 1
🧪 Testing

Test all 9 rock-paper-scissors combinations. For the guessing game, test a guess that is too low, too high and exactly right. Common bugs: picking a new secret inside the loop, and forgetting int() on the guess.

✨ Fun facts
• Rock Paper Scissors is thought to come from a hand game played in China around 2,000 years ago.
• Guessing the middle each time is called binary search — it halves the possibilities with every guess.
• Computers cannot make truly random numbers on their own; random gives “pseudo-random” numbers from a clever formula.
