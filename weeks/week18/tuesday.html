Nested Loops — Star Patterns & Tables
A nested loop is a loop inside a loop. “The inner one finishes completely each time the outer one runs once.”
🪆 How nesting works
for i in range(2):          # outer: rows
    for j in range(3):      # inner: columns
        print("*", end="")
    print()                 # new line after each row

Output: two rows of ***. The inner loop runs 3 times for each outer pass: 2 × 3 = 6 stars.

⭐ Star patterns
# right triangle
for i in range(1, 5):
    print("*" * i)

# inverted triangle
for i in range(4, 0, -1):
    print("*" * i)

# pyramid of height 4
n = 4
for i in range(1, n + 1):
    print(" " * (n - i) + "*" * (2 * i - 1))
✖️ Multiplication tables
for i in range(1, 11):
    for j in range(1, 11):
        print(i * j, end=" ")
    print()

That is 10 × 10 = 100 products. The outer loop controls rows; the inner loop controls columns.

✨ Fun facts
• A computer screen is a grid of pixels — drawing it is like a nested loop over rows and columns.
• A full 10 × 10 times table has 100 answers, but only 55 are different if you count 3 × 4 and 4 × 3 as the same.
• Chessboards, calendars and spreadsheets are all grids that programmers draw with nested loops.

🎯 Must-remember
• inner loop finishes fully for every outer pass
• total runs = outer × inner
• print() after the inner loop = new row
• indentation decides which loop a line belongs to
