Dictionary Practice + Tuples
Use dictionaries for real jobs — a phone book, a marks register, a word counter — and meet tuples: lists that can never change.
📞 Phone book and marks
phone = {"Ria": "98450", "Om": "99000"}
print(phone["Om"])
phone["Om"] = "91111"          # update

marks = {"Ria": 80, "Om": 60, "Zoya": 100}
avg = sum(marks.values()) / len(marks)   # 80.0
best = ""
top = -1
for name in marks:
    if marks[name] > top:
        top = marks[name]
        best = name               # Zoya
🔤 Word counter
words = "to be or not to be".split()
count = {}
for w in words:
    count[w] = count.get(w, 0) + 1
print(count["to"])   # 2

.split() breaks a sentence into a list of words.

📦 Tuples
point = (3, 4)
print(point[0])      # 3
x, y = point         # unpacking
days = ("Mon", "Tue", "Wed")
one = (5,)           # a one-item tuple needs a comma
point[0] = 9         # TypeError — tuples cannot change

A tuple is immutable (unchangeable). Use it for things that should stay fixed: coordinates, days of the week. Lists use [ ] and can change.

🔀 Handy tricks
a, b = 1, 2
a, b = b, a              # swap! a = 2, b = 1
(1, 2) + (3,)            # (1, 2, 3)
(5, 7, 5).count(5)       # 2
places = {(0, 0): "origin"}   # tuples can be keys
✨ Fun facts
• Python’s swap trick a, b = b, a works by packing the values into a tuple and unpacking them again.
• GPS positions are pairs of numbers (latitude, longitude) — a perfect job for a tuple.
• Because tuples cannot change, Python can store them a little more efficiently than lists.
