🔢 Place value & rounding

Reading a number by places

Place value = digit × the value of its place. In the Indian system, from the right: Ones, Tens, Hundreds, Thousands, Ten-thousands, Lakhs.

In 4,52,310 the 5 sits in the ten-thousands place → place value = 5 × 10,000 = 50,000. (Its face value is just 5.)

Rounding off

Look at the digit immediately to the right of the place you are rounding to. Less than 5 → round down. 5 or more → round up. Every digit to the right becomes 0.

7,438 to the nearest hundred: the tens digit is 3, which is less than 5, so the hundreds stay → 7,400.

Greatest & smallest numbers

Greatest → digits in descending order. Smallest → ascending order, but 0 can never be the first digit, so swap it with the next one.

Digits 3, 0, 8, 5 → greatest = 8530, smallest = 3058 (not 0358).
🧮 HCF, LCM & primes

HCF and LCM

HCF — the greatest number that divides all of them. LCM — the smallest number that all of them divide into.

16 = 2⁴, 24 = 2³ × 3 → common part 2³ = HCF 8.
5, 10 = 2×5, 15 = 3×5 → 2 × 3 × 5 = LCM 30.
💡 Check yourself: the HCF is never bigger than the smallest number, and the LCM is never smaller than the largest number.

Prime numbers

A prime has exactly two factors — 1 and itself. Between 1 and 10 the primes are 2, 3, 5 and 7. Remember: 1 is not prime, and 2 is the only even prime.

Sum of the primes between 1 and 10 = 2 + 3 + 5 + 7 = 17.
🍕 Fractions & integers

Fraction → percentage

Multiply the fraction by 100 and write %.

3/5 × 100 = 60% · 1/4 = 25% · 2/5 = 40% · 7/10 = 70%

Mixed → improper fraction

(whole × denominator) + numerator, all over the same denominator.

4 ⅔ → (4 × 3) + 2 = 14 → 14/3.

Integers: the two rules that matter

1. Subtracting a negative adds. Two minus signs together become a plus: −(−3) = +3.
2. Different signs → subtract and keep the sign of the larger number.

(−12) + (+15) − (−3) → −12 + 15 + 3 → 3 + 3 = 6.
Successor of −45 = −45 + 1 = −44 (successors always move right on the number line).
📐 BODMAS, shapes, angles & units

BODMAS order

Brackets → Orders → Division & Multiplication left to right → Addition & Subtraction left to right.

30 ÷ 5 × 2 + 4 → (30 ÷ 5) = 6 → 6 × 2 = 12 → 12 + 4 = 16. Do not do 5 × 2 first — division comes first here because it is further left.

⚡ Physics · Day 2 · Matter
Liquids, Gases & Changes of State
How liquids and gases behave, and how matter changes state when heated. Read the cards, then take the quiz.
💧 Liquids

Properties of liquids

Weak intermolecular force, more space than solids, molecules free to move within a boundary → no definite shape (takes the container's), definite volume, almost incompressible, can flow.

Viscosity: a liquid's opposition to flow (honey > water). Surface tension: pulls molecules inward → liquids form spherical drops. Liquids have one free surface.
💨 Gases

Properties of gases

Negligible intermolecular force, very large space, molecules move freely everywhere → no definite shape or volume, highly compressible, very fast diffusion, no free surfaces.

💡 Gas pressure = molecules constantly colliding with the container walls.
🔥 Changes of State

Melting & Boiling

Solid → Liquid (melting/fusion): heat lets molecules overcome forces and move freely. Melting point of ice = 0°C.
Liquid → Gas (boiling/vaporisation): heat makes molecules move fast and escape. Boiling point of water = 100°C.

🖥️ The environment

IDLE and the .py file

IDLE = Integrated Development and Learning Environment, the editor bundled free with Python. Programs you save get the extension .py.

A comment starts with # — Python ignores the rest of that line. Comments explain code to humans.
# find the area of a rectangle area = 10 * 6 print(area) # 60

Case sensitivity

Python is case-sensitive. print, Print and PRINT are three different names — only lowercase print is the built-in function. The same applies to your own variables: Total and total are two separate boxes.

📦 Variables & data types

A variable is a named box

You store a value by giving it a name with =. Python works out the type on its own — you do not declare it.

marks = 95 # int temp = 98.6 # float — it has a decimal point name = "Riya" # str — it is in quotes passed = True # bool

Careful with // and %

Think of ordinary division with a remainder: 15 ÷ 4 gives quotient 3, remainder 3. So 15 // 4 is the quotient 3, and 15 % 4 is the remainder 3. They happen to match here — try 17 // 5 = 3 and 17 % 5 = 2 to see the difference.

💡 n % 2 == 0 is the standard test for an even number.

Strings repeat with *

Multiplying a string by a whole number repeats it; adding two strings joins them.

print("Py" * 3) # PyPyPy print("Py" + "thon") # Python
📤 Input & output

print() and input()

print() displays text or the value of a variable. input() takes what the user types — and always hands it back as a string, so wrap it in int() or float() for calculations.

name = input("Name: ") age = int(input("Age: ")) # now a number print("Hello", name, age + 1)
🔀 Decisions & repetition

if / elif / else

A conditional block begins with if, the header line ends with a colon :, and the lines belonging to the block are indented (normally 4 spaces).

if marks >= 90: print("Excellent") elif marks >= 50: print("Pass") else: print("Try again")

Why indentation matters

Most languages use curly braces { } to mark a block. Python uses indentation instead — it is how the interpreter knows which lines are inside the block and which are outside. Get it wrong and Python stops with an IndentationError, or worse, runs the wrong lines.

Indented under the if → runs only when the condition is True. Not indented → runs every time.

Loops — repeating a block

When a block must run repeatedly you use a loop. A for loop is for a known number of repetitions; a while loop repeats as long as a condition stays True.

for i in range(3): # 0, 1, 2 — exactly 3 times print("Hello")
