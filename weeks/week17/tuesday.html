For Loops — Strings, Lists & Patterns
A for loop can walk through each letter of a string or each item of a list — no range() needed.
🔤 Looping through a string
for letter in "Python":
    print(letter)

Prints P, y, t, h, o, n — one character per line. Spaces count as characters too.

📋 Looping through a list
fruits = ["apple", "mango", "kiwi"]
for f in fruits:
    print(f)
🔢 Numbering items
for i, f in enumerate(fruits, 1):
    print(i, f)
# 1 apple
# 2 mango
# 3 kiwi

enumerate gives the position and the item together. Without it: for i in range(len(fruits)): then fruits[i].

🧮 Useful patterns
# count vowels
count = 0
for ch in "education":
    if ch in "aeiou":
        count = count + 1

# reverse a word
new = ""
for ch in "loop":
    new = ch + new      # "pool"

# print on one line
for ch in "Hi!":
    print(ch, end="")
✨ Fun facts
• A palindrome reads the same backwards — “level”, “madam”, “racecar”. You can test one with a loop that reverses the word.
• The longest English word in many dictionaries, “pneumonoultramicroscopicsilicovolcanoconiosis”, has 45 letters — a loop could count them in a blink.
• Python lists can hold different types together: [1, "two", 3.0].

🎯 Must-remember
• for ch in word: one character at a time
• for item in my_list: one item at a time
• enumerate(list, 1) numbers from 1
• end="" keeps printing on the same line
