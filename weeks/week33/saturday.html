🧬 Saturday · Week 33 · Puzzle day
Odd one out 🕵️‍♀️
Every odd-one-out puzzle hides a rule. Find the rule that three items share — the one that breaks it is your answer.
🧠 How to solve
StepDo this
1Say what each item is (organ? disease? vitamin? plant?)
2Look for a shared group: same chapter, same job, same cause, same habitat
3Check that ONLY one item breaks the rule
4Be ready to say the rule — exams ask "give a reason"
✏️ Worked examples

Pepsin, trypsin, erepsin, bile

Rule: enzymes that digest protein → bile is odd (no enzyme at all).

Camel, cactus, desert rat, yak

Rule: desert living things → yak is odd (mountains).

Malaria, dengue, filariasis, cholera

Rule: spread by mosquitoes → cholera is odd (contaminated water).

🎯 Puzzle Trivia
• 🧩 Sometimes two rules work — choose the one that leaves exactly ONE odd item.
• 🔤 Watch spelling look-alikes: "pollination" vs "pollution", "ileum" vs "ilium".
• 🧠 Puzzles like these build the classification skill scientists use to name every living thing.
